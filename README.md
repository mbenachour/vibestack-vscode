# VibeStack File Tree

A VSCode extension that displays the file tree of your current repository in a custom view.

## Features

- Displays complete file tree of the workspace
- Shows folders and files with appropriate icons
- Click files to open them in the editor
- Automatically refreshes when workspace changes

## Installation & Development

1. Install dependencies:
```bash
npm install
```

2. Compile the extension:
```bash
npm run compile
```

3. Press F5 in VSCode to open a new Extension Development Host window

4. The "VibeStack File Tree" view will appear in the Explorer sidebar

## Usage

Once installed, the file tree view automatically appears in the Explorer sidebar. Click on any file to open it in the editor.

## Building

To compile the extension:
```bash
npm run compile
```

To watch for changes during development:
```bash
npm run watch
```
